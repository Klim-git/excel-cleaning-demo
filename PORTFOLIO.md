# Текст для портфолио

Название: Объединение и очистка Excel на Python

Разработал скрипт для объединения нескольких Excel-файлов со списками организаций. Скрипт нормализует телефоны и email, удаляет точные дубли и отмечает записи с ошибками или недостающими данными.

Результат: единая таблица Excel и CSV, отчёт обработки, журнал удалённых дублей и связь каждой записи с исходным файлом.

В демонстрации обработано 18 строк из трёх файлов: сохранено 15 записей, удалено 3 дубля, 4 записи отмечены для проверки. Филиалы с общими контактами сохранены отдельно.

Стек: Python, openpyxl, Excel, CSV.

Моя роль: разработка скрипта, правил обработки, выгрузки и проверок.

Данные вымышлены. Работа выполнена как демонстрационный проект для портфолио.
